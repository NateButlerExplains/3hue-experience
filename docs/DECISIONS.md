# Decisions

## Why a new repo, not the fork
GitHub Pages project URLs are fixed by the repo name, so `natebutlerexplains.github.io/3hue-experience` needs a repo called `3hue-experience`. The fork (`NateButlerExplains/3Hue-Market-Intel`) keeps its name and its upstream link and stays the system of record for the dashboard, the priced catalog, the source library and the original acceptance register. This repo is the buyer-facing static site only: no framework, no build, no runtime dependency, relative paths only so the tree can later be copied into `3hue.net/experience/`.

## Overrides carried from the level-up register (`docs/levelup/overrides.md`)
- **O1** Buyer labels: SaaS & AI vendors / Portfolio owners / Regulated operators.
- **O2** Every "Talk to our team" resolves to https://3hue.net/contact.html, new tab, `rel="noopener noreferrer"`.
- **O3** Customer share links stay inside Experience navigation: a deep link has exactly the lobby beneath it, never a dashboard entry. There is no dashboard here, so the staff stack does not exist.
- **O4** The supplied clean plate is accepted with its upper navy band retained.

## New overrides for this build
- **O5 Rendered rooms.** LEVELUP.md line 86 says no close-up renders are made. Nate decided on 2026-09-10 that each door opens into its own rendered room, AiVRIC style. Renders are generated by Nate in GPT from `tools/room-prompts/*.txt`, pass `docs/RENDER-GATE.md`, and are wired only after his written OK. `?rooms=0` keeps the spec-as-written behaviour (dolly to the door, panel, no room image) and remains supported.
- **O6 Render size.** The spec's "native ≥ 2560×1440, never upscale" is relaxed for rooms the same way it was for the plate: GPT-native output is upscaled locally (Real-ESRGAN x4plus, then downsampled to the 2560 master) and judged at the gate on the result. Text, people, curved or holographic surfaces still fail.
- **O7 Standalone re-scope.** Every acceptance clause that names dashboard chrome (header.topbar, Experience button, Return to intelligence, catalog-shell, admin modal, drawer, `.icp-carousel`, Guide, NB chip, dashboard data) is replaced by its standalone equivalent or removed; viewports, tolerances, timings and counts are kept verbatim. The register with per-check dispositions is `docs/acceptance-standalone.md`.
- **O8 Header link.** The header logo links to https://3hue.net (new tab). There is no "Return to intelligence".
- **O9 Kiosk.** The kiosk shows counts derived from this manifest at runtime (buyer segments, maturity stages, service families) under a "Representative data" tag, with the "AiVRIC intelligence layer" header line. No dashboard figures exist to read.

## Standing rules
- Content lives in `content/experience.json`; geometry in `content/geometry.json`. JS only templates. `node tools/check-manifest.js` runs before every publish and fails on forbidden or retired vocabulary, customers outside the allowlist, or any research figure without `source` and `status`.
- No sound, no intro film, no invented customers or metrics, no prices, no raw findings or competitor names on any surface.
- `3HUE` is a standard of execution, never an acronym; never "the three hues of security"; ISG/OPS/ITG are never "the three".
- `noindex` stays on until Nate lifts it; `robots.txt` allows every bot so link previews still work.
